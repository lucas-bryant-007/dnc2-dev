# Pretrained strict cross-fit paper package

This directory contains paper-facing summaries derived from the strict
train-fitted/test-evaluated CelebA and CUB-200 runs in `repro_exports/`.

## Contents

- `summary/strict_pretrained_crossfit_summary.{png,pdf}`: four-panel comparison
  of captured factor energy, aggregate task orthogonality, frozen-corner
  fidelity, and the held-out label-randomization control.
- `summary/strict_pretrained_crossfit_summary.csv`: machine-readable values
  plotted in the summary figure.
- `summary/RESULTS.md`: concise result interpretation, suggested paper text,
  and a suggested figure caption.
- `permutation_nulls/<method>/`: JSON and figures from 5,000 independent
  held-out label permutations.

The label-randomization analysis conditions on the jointly balanced held-out
sample exported by each strict run. It keeps the train-fitted projection and
train-predicted corners frozen and independently permutes the three held-out
factor columns. It tests held-out feature/label association; it does not repeat
train-time triple selection. The separate GPU full-pipeline control is exposed
through `celeba_hyperrect_crossfit.py --label_permutation_seed` and records a
train-selection failure as a result under the unchanged constraints.

## Reproduce the conditional nulls

```bash
python analysis/permutation_box_null.py \
  --json repro_exports/celeba_strict_crossfit_20260723/vicreg/metrics/hyperrect_crossfit_vicreg_celeba_epoch_1000_strict_crossfit_20x500.json \
  --n_permutations 5000 --seed 20260723 \
  --out_dir paper_outputs/pretrained_crossfit_20260723/permutation_nulls/vicreg

python analysis/permutation_box_null.py \
  --json repro_exports/celeba_strict_crossfit_20260723/ijepa/metrics/hyperrect_crossfit_ijepa_celeba_epoch_1000_strict_crossfit_20x500.json \
  --n_permutations 5000 --seed 20260723 \
  --out_dir paper_outputs/pretrained_crossfit_20260723/permutation_nulls/ijepa
```

The summary figure is regenerated by `analysis/plot_strict_pretrained_paper.py`.
Its inputs are the three strict run JSONs and the two permutation-null JSONs.

The 20 balance seeds reuse fixed model features and are not independent
training seeds. The invalid first CUB selector diagnostic is excluded from the
paper summary; only the corrected distinct-family result is included.
